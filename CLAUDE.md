# Project rules

## Git workflow

Never commit directly to `main` or push to `origin/main`. For any change:

1. Create a feature branch locally (`git checkout -b <short-descriptive-name>`).
2. Commit the work there and push the branch.
3. Open a pull request with `gh pr create` and share the PR link.

Merging is the user's call — do not merge or delete branches unless asked.
